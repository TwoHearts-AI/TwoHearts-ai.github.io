Сервис принимает экспорт переписки и собирает структурированный отчет о повторяющихся паттернах коммуникации. Это продукт для саморефлексии, не диагноз и не терапия.

От загрузки чата до отчета с понятной структурой.

MVP включает Telegram bot/WebApp, backend API, worker-обработку, RAG/LLM-модуль, object storage, контур обезличивания и статический публичный сайт проекта.

01

Импорт переписки

Пользователь загружает экспорт чата через Telegram-сценарий; сервис фиксирует прогресс обработки и готовит данные к анализу.

02

Аналитический пайплайн

Backend и worker-контур обрабатывают JSON, запускают анализ и собирают результат в формат отчета.

03

Отчет для чтения

Итоговый материал показывает темы, тональность, повторяющиеся конфликтные места и аккуратные практические наблюдения.

Пользовательский сценарий

Три действия вместо длинной анкеты.

Сценарий сделан для mobile-first использования в Telegram: загрузить файл, дождаться обработки, открыть отчет.

Загрузить экспорт

Пользователь передает выгрузку переписки и видит, что файл принят в обработку.

Дождаться анализа

Сервис проходит этапы обработки: прием, подготовка, анализ, сборка результата.

Открыть отчет

Результат доступен как структурированный материал, который можно прочитать без технических деталей.

Безопасный пример

Демо-отчет использует синтетические данные.

Публичные sample pages не содержат сырой личной переписки. Для демонстрации оставлен synthetic report с вымышленными сообщениями, без контактов, usernames, телефонов и Telegram ID.

Границы

TwoHearts_AI не заменяет специалиста.

Сервис предназначен для анализа коммуникации и саморефлексии. Он не ставит диагноз, не оказывает медицинскую, психологическую, юридическую или терапевтическую услугу и не должен использоваться для критических решений без человека.

Данные

Публичный контур отделен от пользовательских данных.

Рабочий MVP использует backend-обработку и object storage для загружаемых файлов. Публичные страницы и отчетные proof-материалы должны содержать только обезличенные агрегаты, synthetic demo и визуальные скриншоты без raw-чата.
